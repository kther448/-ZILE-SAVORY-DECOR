# ZILE SAVORY & DECOR

A five-page English/French responsive website for Isabelle Jerome's Haitian-inspired catering and event decoration company.

## Pages
Home (`index.html`), Services (`services.html`), Gallery (`gallery.html`), About (`about.html`), and Contact (`contact.html`).

## Deploy
Enable GitHub Pages in **Settings > Pages**, selecting `main` and `/ (root)`. No build tool is required.
