# ZILE SAVORY & DECOR — website

A responsive, five-page bilingual (English/French) website for Isabelle Jerome's catering and event decor business. Built with plain HTML, CSS, and JavaScript — no build tools or dependencies.

## Pages

- `index.html` — Home
- `services.html` — Catering, appetizer tables, decorations, spices & pikliz
- `gallery.html` — Filterable photo gallery, lightbox
- `about.html` — Isabelle's story
- `contact.html` — Booking links and FAQs

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080`.

## Publish on GitHub Pages

Upload **all files and the complete `assets/`, `css/` and `js/` folders** to the repository root. Go to repository Settings > Pages > Deploy from a branch > `main` / `/ (root)` and save.

The provided GitHub repository name starts with a hyphen, so the Pages URL (if enabled) may use that exact folder segment. You can connect a custom domain later.
